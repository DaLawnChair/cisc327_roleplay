# regading ability for books
* The system shall show the availability of a given book without needing to explicitly search for it on the shelves 
* The system shall show my current account status, the status of every book book I have (ie if its late, and by how much), and the due date for each lent item without asking the front desk
* The system shall allow me to reserve an available book and hold a currently lent book to allow me to get ahold of the requested book at its earliest availability
* The system shall allow book renewals if there are no holds for the book 

# regarding late returns
* The system shall offer a grace period for returning books for 3 days before any charge is sent.
* The system shall provide reminders via email to notify of upcoming due dates for lent items
* The system shall allow users to notify the library of possible late returns, in order to notify that the late return is possible
* The system shall allow the a representative/automated message from the library to contact me if I am late to return a book on the last day of the grace period 

# regarding login
* The system shall default the library card number as the login for the library interface

# additional requirements I think are important
* The system shall keep track of and show the history of my checkout and returns
